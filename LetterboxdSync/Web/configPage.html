Help improve Jellyscribe with anonymous telemetry?

If you turn it on, the server sends a weekly ping with versions, which features are on, usage counts in rough buckets, and how many of each kind of sync error happened that week. When a new kind of error starts, one extra ping goes out straight away (at most one a day). Never titles, usernames, emails or library contents. You can turn it off any time in Integrations.

Logs

Recent plugin log lines. Passwords, cookies and tokens are never logged, and email addresses are masked.

This uploads a diagnostic bundle so the developer can look into a problem. Unlike anonymous telemetry, it is not anonymous. It holds:
  • up to the last 500 Jellyscribe log lines from the server's two newest log files, like the ones below. They name films, shows, Jellyfin users and Letterboxd usernames, and can quote error messages from Letterboxd, Serializd and Seerr. Email addresses are replaced with [email]; passwords, cookies and tokens are never logged.
  • the plugin and Jellyfin versions, and which log files were read
  • the telemetry snapshot that Integrations › Preview shows, and this server's telemetry ID (if it has none, a one-off ID kept until the server restarts), so the bundle is tied to this server
  • your note, if you write one
It is stored privately for 90 days. You get a reference code to quote in a bug report. Nothing is sent until you click Send bundle.
